# SMNX native model input schema
## Purpose and Scope
Parent [Exchange](../DESIGN.md). Children: none. Owns versioned self-contained model-input/inline-asset values and caller limits. Runtime checkpoints are separate and no Runtime type is imported.
## Responsibilities and Boundaries
Version1 preserves current Compiler descriptor fields in source order: identity/revision, bodies, joints, root/base/coordinate authority/world frame, initial q/v/acceleration/time/revision and prescribed anchor motion samples, representation requirements, required features and extension records. Canonical Compiler layout order is established only by recompilation. Body motion tags preserve producer semantics exactly: 0=static (fixed motion), 1=prescribedKinematic (caller-prescribed motion), 2=dynamic (force-driven). All current planar/spatial body modes, base layouts, joint kinds including custom ordered axes, fixed/prescribed anchor placement, producer inertia origins/quality and representation quality are represented. State is the model initial condition, not an accepted Runtime continuation or cache.

```text
MechanicalDescriptor + inline opaque assets -> SMNX v1 model input document
```

## Contracts and Invariants
Header is ASCII SMNX (4 bytes), version UInt64=1, unit tag UInt8=1 (canonical SI). Every unsigned count/revision is UInt64 little-endian; Double fields are finite IEEE754 binary64 little-endian bits; signed SI dimension exponents are eight Int8 bytes in Core length/mass/time/angle/current/temperature/amount/luminous order. Boolean tags are exactly0/1. UTF8 text is UInt64 byte length followed by strict UTF8, with no normalization or repair. Array is UInt64 length then records. Record order and signed zero bits remain unchanged. Enum mapping and field order are defined by the owned NativeWireTags/NativeWireWriter/NativeWireReader source; unknown tags, extra trailing bytes, incompatible header/version/units fail (no skip policy).
Document includes an inline asset list after the descriptor: key, format, source provenance, revision, counted byte payload. Asset key is a nonempty logical ASCII token [A-Za-z0-9_-], explicitly based in this document's embedded asset table; paths/URLs and external resolution are outside this domain and rejected. Format whitelist admits opaque bytes only, not physical mesh/law correctness. Duplicate asset keys and entity definitions use Swift/Model Unicode-semantic equality, not byte sorting. Every geometry representation asset key must exist and exactly match source/revision provenance. Extra assets may be retained; no semantics silently discarded. Required extension schemas/features must belong to caller admission lists; the Compiler's actual validator still decides physical law domain.
Public decode reports the maximum component correction when constructing producer unit quaternions/axes and the number of corrected unit records. Caller nonnegative finite maximumUnitComponentCorrection<1 bounds this explicitly configured normalization; excess fails. q/v/acceleration/law values and identity/provenance bytes are never numerically canonicalized. Inertia reconstruction uses caller producer validation policy and requires exactly retained tensor elements; noncanonical asymmetric input is rejected rather than mixing inertia units with a dimensionless unit-vector correction bound. Corrections can affect Compiler's exact revision-migration equivalence; callers requiring exact geometry choose bound0 and must handle rejection.
## State, Ownership, and Lifecycle
Immutable Sendable documents/assets/results/policies. Caller-owned mutable ExchangeWork accumulates per operation; no shared state/caches or platform conditional storage. Temporary byte owner does not escape decode. Inputs are borrowed immutable values and returned records own their arrays/text.
## Failure, Concurrency, and Constraints
Limits are caller-selected, nonnegative. Wire byte limit checked before decode traversal. Counts, remaining minimum wire size, cumulative records/elements/metadata and logical allocation payload bytes checked before reserve/copy. Storage accounts requested Array element strides and decoded text/payload byte lengths, excluding caller input storage and allocator/runtime overhead. Encode measures full output before allocating one output byte buffer; both passes charged. Byte traversal, normalization and semantic admission comparisons charged; cancellations checked during traversal and before publication. No wall-clock/allocator-total/zero-allocation claim.
