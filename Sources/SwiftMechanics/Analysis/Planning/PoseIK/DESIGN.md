## Architecture
```text
immutable tree + identified SI coordinate layout + tasks + original loop rows
    -> bounded admission / explicit initial and reference configurations
    -> normalized x=q/S; fixed-time tree snapshot
    -> actual point / local orientation residual and analytic Jacobian
    -> exact tree directional products -> residual Hessian contractions
    -> equality KKT equations -> qualified bounded nonlinear solver
    -> original points / rotation matrices / polynomial rows / bounds / row rank
    -> immutable feasible query candidate or typed failure with available witness
```

## Contracts and Invariants
Identity includes user query ID, tree revision/world/body-frame IDs, immutable tree value, coordinate IDs/dimensions/scales and ordered task/loop row IDs. Tasks bind only body-owned frames. Root/anchor geometry is immutable. Coordinate layout order equals tree order; each prismatic factor uses metres and each revolute/screw factor radians. The selected q-v map is identity before scaling; floating and quaternion-storage charts are refused. Query time is frozen; v and acceleration are exactly zero. Time-dependent quadratic loop coefficients are evaluated at that time; prescribed anchors are unsupported.

Tasks have three identified rows for a point or orientation, six for a pose. All residuals are dimensionless: point displacement divided by explicit length scale, orientation residual divided by explicit angular scale, original loop polynomial unchanged. Orientation uses E=Rtarget^T Rbody and r=vee(E-E^T)/2. The caller's branch requires cos(angle)=(trace(E)-1)/2 greater than a finite margin in [0,1), so the selected angle is strictly below90 degrees. This excludes the false skew root at180 degrees. Original orientation acceptance compares the complete rotation matrix Frobenius distance, independently of skew residual. No logarithm, quaternion sign choice, angle wrapping or branch switching occurs.

Let f collect every original task and loop row, m<=n, x=q/S, and xr be explicit reference coordinates. Solve F=[x-xr+J^T lambda; f]=0. Its exact tangent is [[I+sum(lambda_a H_a),J^T],[J,0]]. Point H uses exact directional geometric columns and transported point offsets; orientation H differentiates [omega]R using exact angular-column and rotation-matrix products; loop H is the original symmetric coefficient matrix. No finite difference production derivatives or deleted redundant rows. The reference objective is initialization metadata for selecting a local equality-stationary feasible candidate; no local-minimum/global-nearest/global-infeasibility claim is made. Multipliers are query covectors, never forces.

All successful candidates satisfy original target tolerances, every loop tolerance, finite coordinate bounds, selected orientation branch and independently analyzed full task/loop row rank. Rank failure rejects an already solved initial guess too. Bounds are an admitted search domain, not active-set optimality conditions; no active-bound optimum claim is made. Overdetermined or redundant task systems, collision constraints, maximal/floating/quaternion charts and multi-branch enumeration are typed refusal with callable incomplete markers. Failure to find a candidate reports nonconvergence or singularity; it is not proof of impossibility. Rankless failed-iterate evidence retains original physical errors but does not assert feasible accepted output.

## Runtime Flows
Admission freezes metadata, original rows and initial/reference positions. The full query coordinate box must be inside every supplied loop system's original box; supplied rows and supplier domain are never edited. Build normalized initial x and zero query multipliers. The nonlinear provider validates bounds and local orientation branch on each candidate, computes original target equations from the actual primal supplier and uses qualified exact products for KKT tangents. IM04 owns iterations, line-search rejection, derivative probes and last-iterate diagnostics. A derivative probe crossing the admitted boundary explicitly fails; the component does not clamp it or relax bounds. After solver acceptance, independently recompute original points/matrices/polynomial values, verify rank and reject any failed tolerance. On ordinary no-step/singular/nonconverged solve failure, attempt a bounded original last-iterate witness. Cancellation/resource/supplier failure stops without retrying a failed supplier. Failure retains the original nested solve diagnostics; SI final positions and original witnesses are explicitly unavailable if the residual budget cannot materialize them.

## State, Ownership, and Lifecycle
All public inputs/results and services are Sendable immutable values. Mutable arrays, NumericalWork and TreeTangentWorkspace are exclusively local to one synchronous operation/callback. No shared state, target-specific isolation branches, raw pointer escape or unsafe fallback. Result owns its state and evidence. Solver candidate never becomes an accepted simulation state.

## Failure, Concurrency, and Constraints
Typed failures distinguish invalid/stale identity, unsupported domains, unavailable derivatives, numerical/supplier failures, singular rank, original target/loop rejection, cancellation and nonconvergence. Preserve nested NonlinearFailure and consumed work. IM04's closed provider error contract carries failed callback categories:330102 geometry,330103 constraints,330106 kinematics,330100 other; exact derivative failures use invalidDerivative, with nested numerical/cancellation causes preserved as numerical failures. These callback categories do not fabricate detailed supplier diagnostics unavailable through that contract. Task/coordinate/body/identity-byte limits precede input traversal and output allocation. Checked integer arithmetic determines conservative simultaneous scalar storage for solver arrays, primal snapshots, exact derivative publication/workspace, row matrices and retained original input coefficients. Each callback preflights its combined bound; nested solver budget reserves outer input/evidence storage, and nested work is absorbed even on nonlinear failure. Primitive tree calls are explicitly charged as invocations; unavailable internal supplier arithmetic is never represented as measured work. Exact derivative supplier calls have an explicit per-direction cap; aggregate invocation count is bounded by charged callbacks, coordinate count and numerical iteration/operation budgets. Cancellation checks occur during admission, each direction and final publication.
