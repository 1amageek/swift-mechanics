# Held-effort rigid plant through existing RK4

## Purpose and Scope
Parent: [Control](../DESIGN.md). Children: none. Own actual initial rigid mechanical plant equation, composition with existing ReferenceExplicitIntegrator classicalRK4, original force/endpoint energy proof and call-local resources. DESIGN precedes source; behavior/profile qualification pending. No second production integration engine is created.

## Responsibilities and Boundaries
Admit a compiled spatial fixed-root two-body/single-prismatic model, static anchors/unit axis, actual positive mass properties on both bodies (the fixed root has zero motion, not fabricated zero inertia) and world/body frames, with one dynamic scalar coordinate and constant interval disturbance effort. Gravity/additional passive/contact/constraint/unknown models are not initially published. Consume TreeKinematics, real RigidEquationComputing and RigidDynamicsSolving; use existing Integration for time evolution. Ports/law/clock and accepted-state ownership remain linked authorities. Exact constant-acceleration formulas are independent test oracles only.

## Architecture
```text
actual session interval -> bound SmoothODE.prepare: real servo + pending contributors
 -> existing RK4 derivative stages: actual tree/rigid assembly + forward solve -> [v,a]
 -> actual endpoint force/energy proof
 -> SmoothODE.write: checked endpoint + ready contributors
 -> original Runtime checkpoint admission/commit -> bound observe release
```

## Contracts and Invariants
The plant equation implements every SmoothODEEquations requirement. Its stable ODEDescriptor binds model/chart/controller configuration and physical [q,v] dimensions; changing held force does not silently change the kinematic chart. read uses actual physical state/trial q/v, never cached scalar stand-ins. prepare changes only declared contributor records and operation-local workspaces; q/v/time remain unchanged as Integration requires. derivative assembles real motion/inertias/conjugate held effort+constant disturbance at each stage, calls the actual forward solve, independently recomputes originalInertialForce and verifies M*a+bias against all selected drive/known force. Poisoned outputs and fixed captured shapes prevent partial writes/metadata mutations from being accepted.

The initial integration policy is caller-owned classicalRK4. For each full sample interval, its initialStep must be at least effectiveDt, its minimumStep must not exceed effectiveDt and its maximumStep must admit initialStep. Call advance to exactly the next sample endpoint. Existing Integration therefore takes one boundary-truncated full interval, with no intermediate accepted controller state or adaptive retry. Heun/adaptive/multiple accepted substeps with this pending controller state are typed unsupported; future support needs interval-aware controller scheduling, not guessed callback dt. Endpoint time/physical chart/returned step evidence must match the captured interval.

At every real derivative stage preserve finite/domain/chart/body/frame/model revision and nested numerical capability diagnostics. Compute the final original mechanics and energy in the actual endpoint derivative callback, where NumericalWork and RuntimeStepControl are available. write receives no numerical ledger in the existing protocol: its bounded copy/codec work is preflighted at prepare, then checked against the privately retained exact endpoint proof and charged to operation-local actuation/control work. It does not perform unbudgeted extra rigid solver calls.

Actual held actuator interval work is appliedEffort*(qEnd-qStart); disturbance work is disturbanceEffort*(qEnd-qStart). Real kernel start/end kinetic energy supplies deltaK. The admitted constant-force translation must satisfy deltaK=heldActuatorWork+disturbanceWork within caller tolerance and independently satisfy original force/momentum residual. Actual power is force times actual rate. Preserve old ActuatorEnergy as its declared start-sample approximation appliedEffort*vStart*effectiveDt; it can differ from the actual interval work and is never used as a complete plant energy certificate. No fake zero energy/reaction or inferred physical bearing wrench is returned. Sampled rate envelope and endpoint envelope are separately checked; an inadmissible endpoint stops before publication.

## Runtime Flows
Interval association precedes allocation/callbacks. Prepare captures and stages future controller state in the bound trial. Existing RK4 evaluates real stage/endpoint mechanics; endpoint evidence is retained only for the matching point/time/derivative. Write checks that evidence and stages ready contributor payloads with physical endpoint. Integration and Runtime complete their own checks; only the bound post-finish observer releases the matching physical result. Reject/failure retains work evidence but discards tentative mechanics/controller records.

## State, Ownership, and Lifecycle
Prepare uses sequential noninline decode/admission, mechanics/drive, original-evidence and contributor-staging phases. Immutable Sendable sample, input, system, driven and prepared reference records retain only the fixed scalar sample, original actuator response and actual assembled system needed by the next phase. These five operation-local records are included in the existing 512-scalar orchestration reservation and are released with the preparation operation; they are neither accepted state nor mutable shared storage. Kinematic snapshot/input construction returns before assembly-ledger/result validation begins. Initial actual system assembly returns before command/drive processing begins, so drive response and validation temporaries are absent from the tree-evaluation call chain. Both original makeState and model.evaluate calls remain in their original order; no supplier traversal is removed. A phase returns before the next begins, so its typed-error and intermediate mechanical values do not remain live across downstream supplier calls. No supplier evaluation is duplicated or reordered, and preflight/work charges, safe-point ordering and failure phase labels are preserved.

Public configuration/result records are immutable Sendable. A fresh private equation and interval workspace exist for one control operation. Because existing prepare/derivative/write callbacks share fallible work/evidence, their operation-local phase storage uses the same let Mutex<State> on Native/WASM/Embedded. The phase stores only tentative scratch/proofs/cumulative ledgers, not mutable accepted controller mirrors. Short checkout/finish critical sections transfer exclusive local workspace with a ticket; supplier callbacks run outside the lock. Reentrant/concurrent phase access is refused. Every exit restores the local ledger/workspace; the operation releases it after the actual session result. No global cache, unsafe pointer, target weakening or second integrator.

## Failure, Concurrency, and Constraints
The public numerical budget equals the Integration supplier budget; it is one authoritative per-step limit, not an unused independent allowance. Fixed two-body stage arrays are bounded ownership copies for actual model/kernel inputs; retained endpoint arrays have two scalars each and are included in the 512-scalar orchestration reservation. Caller fixes graph/model counts, scalar/byte/payload capacities, numerical arithmetic/iterations/fill, actuation/load work, metadata traversal, solver/tolerance/capability, Runtime safe-work blocks and Integration budgets. Checked products/sums and ownership-copy reservations precede allocation; stage work reuses operation-owned buffers or explicit bounded supplier boundary copies. Known successful work is absorbed once; mutable ledgers are all inspected/restored before failure escapes, opaque failed supplier consumption is marked unavailable and never retried. Original closure cancellation authority is restored. Invalid model/domain, original force/energy rejection, failed derivative/solver, mismatched endpoint, cancellation, busy/reentry or resource exhaustion produce typed phase-specific failure with known work and last original evidence.

The bounded phase representation addresses that retained caller frame; original-profile frame/guard evidence belongs to the parent, while all 19 owned physical, continuation, budget and typed-error cases must remain green. Sequential system-input and assembly phases, with assembly preceding the drive phase, remove those unrelated retained temporaries. This is a representation change, not a new plant or solver.
