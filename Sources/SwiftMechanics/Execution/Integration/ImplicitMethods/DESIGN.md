# Implicit methods

## Purpose and Scope
Parent: [Integration](../DESIGN.md). Owns TI-003 source implementation of one-step backward Euler on explicitly smooth Euclidean Float64 ODE charts, plus generalized-alpha/HHT-style second-order structural endpoint equations. The selected original8 Native tests and7 public cases have source-bound evidence; ordinary WASM and Embedded behavior remain unverified. Runtime publication is supported by the Euler entry point; structural endpoint results require a caller-owned Runtime transaction and are not accepted physical states.

## Responsibilities and Boundaries
Owns discretized equations, numerical dissipation coefficients, dimensional residual scaling, nonlinear adapter, finite/layout checks and endpoint acceptance. Providers own physical equations, their exact tangents and admissible model/chart. Qualified Nonlinear owns iteration and its original-residual acceptance. Qualified Runtime owns trial, cancellation, rollback and accepted publication. No implicit method changes an existing explicit continuation contributor or guesses q/v layout.

## Architecture
```text
Euler: accepted Runtime snapshot -> exclusive trial -> unchanged prepared chart
       -> F(y)=y-y0-h*f(t1,y) -> qualified nonlinear solve
       -> fresh original residual -> fresh endpoint derivative
       -> write/read/time/descriptor check -> Runtime accept or typed rollback
Structural: owned (q0,v0,a0) -> Newmark q1(a1),v1(a1)
            -> generalized-alpha weighted q_f,v_f,a_m
               or exact HHT weighted old/new endpoint balances
            -> provider physical residual/tangent -> qualified nonlinear solve
            -> fresh original residual -> endpoint proposal
```

## Contracts and Invariants
`ImplicitODEEquations` and `ImplicitEulerIntegrating` expose operations as protocol requirements. Euler admission requires `.smoothEuclidean`, captured descriptor/model equality, finite nonempty coordinate vectors and a strictly later representable time. Provider tangent is row-major df_i/dy_j. Each row of backward-Euler residual and tangent is divided by the fixed SI scale absoluteSI+relative*abs(y0_i), making the nonlinear acceptance dimensionless. Scales match descriptor dimensions. Fresh derivative evaluation independently recomputes the original backward-Euler equation before returning an endpoint. Unsupported charts, nonsmooth laws and missing tangents fail explicitly; no finite-difference substitution or method fallback.

Structural generalized-alpha convention is `q_f=(1-alphaF)*q1+alphaF*q0`, `v_f=(1-alphaF)*v1+alphaF*v0`, `a_m=(1-alphaM)*a1+alphaM*a0`, with evaluation time `(1-alphaF)*t1+alphaF*t0`. Newmark uses `q1=q0+h*v0+h*h*((0.5-beta)*a0+beta*a1)` and `v1=v0+h*((1-gamma)*a0+gamma*a1)`. For generalized-alpha the provider supplies physical residual R(t_f,q_f,v_f,a_m) and the exact chain-rule tangent `(1-alphaF)*beta*h*h*R_q+(1-alphaF)*gamma*h*R_v+(1-alphaM)*R_a`. Its separate originalResidual requirement must evaluate the original physical balance, not a solver convergence flag. Finite positive caller row reference scales nondimensionalize residuals. Admitted coefficients satisfy alphaM<=alphaF<=0.5, alphaF>=0, alphaM>=-1, gamma=0.5-alphaM+alphaF, beta=0.25*(1-alphaM+alphaF)^2. Factory rhoInfinity in [0,1] yields standard generalized-alpha. HHT alpha in [-1/3,0] yields alphaM=0, alphaF=-alpha and uses the exact weighted endpoint balance `(1-alphaF)*R(t1,q1,v1,a1)+alphaF*R(t0,q0,v0,a1)`, not a weighted-state substitute. Its tangent is the sum of an endpoint tangent with coefficients `((1-alphaF)*beta*h*h,(1-alphaF)*gamma*h,1-alphaF)` and the old-state acceleration tangent with coefficients `(0,0,alphaF)`. Structural admission requires smooth Euclidean, constant-mass balance R=M*a+noninertialBalance(t,q,v); variable mass is an explicit unsupported domain. The HHT formula therefore preserves inertia M*a1 exactly and weights original nonlinear forces/loads at their actual endpoints. These parameter conditions describe the conventional linear structural method; they do not certify nonlinear physical stability or damp all modes.

## Runtime Flows
Euler snapshots accepted identity, validates the provider, enters one exclusive Runtime trial and verifies that its chart/time still equals the expected accepted state. Preparation may change contributor/random trial state but cannot change chart/time. Solve, endpoint checks and publication use Runtime cancellation safe points. Any failure terminates the trial; no automatic retry. Runtime returns the authoritative accepted state. Stateless Euler requires no multistep history; caller continuation contributors remain the caller's responsibility. Existing integrator-category contributors are rejected because this entry point cannot update another method's history.

## State, Ownership, and Lifecycle
All policies, descriptors and input/result arrays are owned immutable Sendable values. Nonlinear adapters are scalar-generic to preserve qualified Embedded witness specialization. Euler capture uses the same `Mutex` storage and access on all targets. Structural callback workspace uses the same `Mutex` on all targets; arrays are borrowed by value inside a short lock, then callbacks execute outside it, and workspace is returned afterward. No target-specific synchronization weakening, unsafe pointer or Foundation dependency. Reusable scalar-generic adapter conversion/tangent arrays are taken from `Mutex<Workspace?>` and returned after the callback. Only one synchronous solve owns an adapter instance; no provider callback is executed while a metadata lock is held.

## Failure, Concurrency, and Constraints
Typed causes distinguish invalid input, unsupported domain, Runtime, Numerical and Nonlinear failure. Euler failures preserve last accepted state and known work; nested unknown work is marked unavailable. Provider ledgers cannot change budget or decrease counters; detected replacement restores the last known ledger and fails, with unavailable supplier work. No success or retry follows unavailable work. Counts/products are checked. Caller budget includes retained input/scales, adapter workspace, nonlinear workspace, outputs and final original acceptance; derived solver budget reserves retained storage. Arithmetic is charged before loops, provider work is charged through its supplied ledger, and provider output is poisoned and finite/shape checked. Runtime control is checked before/after Euler callbacks; nonlinear cancellation applies to structural callbacks. Dense factor capacity and nonlinear iterations remain caller policy. There is no hidden accumulated history or resource.
