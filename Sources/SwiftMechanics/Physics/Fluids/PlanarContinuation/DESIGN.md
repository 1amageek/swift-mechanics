# PlanarContinuation

## Purpose and Scope
Initial admitted implementation domain; behavioral/profile qualification pending. Parent [Fluids](../DESIGN.md); no children. Own bounded exact periodic MAC field continuation, required Runtime contributor admission and actual trial/accept/reject/checkpoint/restart. Full EX-005 remains open outside this static-carrier domain.

## Responsibilities and Boundaries
Publish immutable context-bound binary state and compose public Runtime/Planar operations. One compiled spatial static root, fixed base/authority and inertial world frame, no joints or q/v, one required fluid contributor, one fluid step per accepted transaction. Grid geometry/material/frame/source, model identity/revision and codec tolerance remain immutable. The public MAC service owns original pressure/momentum/work acceptance; this child does not duplicate its discretization or infer moving-grid/FSI physics. Runtime owns exclusive transactions, RNG, accepted-prefix publication and global checkpoints. The fluid operation never draws RNG; caller trial draws are rolled back/replayed by Runtime.

## Architecture
```text
immutable grid/model/codec context -> bounded signature + full field bytes
Runtime whole checkpoint -> per-call immutable time/sequence association
 -> actual core required-contributor admission -> validated accepted state
exclusive Runtime trial -> decode/time check -> public MAC step
 -> encode/local physical checks -> safe point -> replace/time -> core admission/publication
```

## Contracts and Invariants
Wire version 1: little-endian UInt64 words, exact Double bit patterns. Header magic/version and five length-prefixed UTF8 context strings (grid ID, frame key, source name, model identity, contributor ID); grid/source/model revisions, nx/ny and caller cell/metadata limits; lengthX/lengthY/depth/rho/mu and speed/pressure/acceleration/step envelopes plus divergence tolerance. No foreign string decode is needed: compare the complete admitted immutable signature bytes. Dynamic words are time [s], sequence, held uniform acceleration x/y [m/s²], then all N u, N v [m/s] and N pressure [Pa] in published MAC order. Encoded length is fixed by this context; truncation and extension fail. Header context changes, including policy/envelopes, are stale. Restored bytes reconstruct the public PlanarSource and PlanarState, checking finite/domain/count/pressure gauge and all-cell original discrete divergence [1/s] against codec tolerance. Historical pressure is retained exactly; it is not claimed to certify a pressure equation without its previous tentative field.

Local contributor validation cannot know physical checkpoint time. PlanarRuntimeCheckpointHandler.admit constructs a per-call immutable association (checkpoint.physical.time, checkpoint.acceptedSteps) and passes its contributor to the real ReferenceRuntimeCheckpointHandler. The required validator decodes once under the actual Runtime validation budget, then requires field.time and field.sequence to equal that association before core publication. Initial admission, restart and accepted trials therefore cannot publish mismatched time/sequence. Its required registry contains exactly this schema. Local standalone contributor validation proves payload/carrier only. Trial entry independently checks decoded time equals trial.timeSeconds before stepping. A step must preserve exact grid/source binding and advance time and sequence exactly once; the whole handler enforces one step per accepted transaction. No numerical convergence implies additional physical validity.

The required supplier invocation phase admits one NumericalWork operation for the boundary ledger guard, then snapshots the complete known pre-invocation value. This nonzero operations marker makes a fresh same-budget reset observable even when the caller initially has zero counters. After either successful or failed PlanarFlowOperating.step, budget must be unchanged and operations/iterations/peak storage cannot decrease. Successful MAC stepping must additionally increase operations and iterations and report nonzero peak storage, reflecting this admitted pressure-solve domain. Ledger corruption restores the known pre-invocation snapshot, raises typed supplierLedgerFailure with unavailable supplier work, and stops without retry; no estimated lost work is substituted. This verifies observable ledger integrity, not the honesty of arbitrary fabricated monotone counters. The marker is a documented numerical boundary operation, distinct from byte-validation and Runtime safe-point units.

## Runtime Flows
Context admission and checked length products precede signature/buffer allocation. Byte work owns peak live storage and conservative logical validation units; signature/record metadata bytes and dynamic words are charged before traversal, with row-boundary cancellation. Metadata admission charges three units per iterator advance/end check, covering subsequent bounded raw-byte comparisons; codec physical admission reserves 16+64*N units before field traversal/allocation, including public state reconstruction and local scalar checks. Peak codec storage reserves wire+signature+48*N bytes, covering simultaneously live old/new field arrays during trial encoding; public MAC temporary workspace has its separate NumericalWork ledger. Public MAC receives the separate caller NumericalWork and unchanged PlanarPolicy. Runtime safe points each admit one Runtime unit before binding/decode, before solve, after solve, and before publication. All successful supplier work stays in NumericalWork; failed supplier unavailable-work Boolean is preserved in RuntimeFailure, with no retry. Encoding/decoding failure or cancellation publishes no trial field; Runtime failure retains the complete last accepted checkpoint and RNG. Whole global checkpoint framing is supplied by NativeRuntimeCheckpointCodec, not duplicated here.

## State, Ownership, and Lifecycle
Immutable Sendable codec/context/provider/output; buffers call-owned, work exclusive inout. Handler association is per-call value state, never a hidden cache. RuntimeSession owns its existing Mutex-protected workspace lifecycle; test cancellation uses the same Mutex contract on all targets. No pointers, registry handles, target-dependent storage/conformance or unsafe Sendable. Owned wire and reconstructed arrays are necessary checkpoint/owner boundaries; cell loops reuse buffers without per-cell allocation. Phase functions are non-inlined to bound Embedded debug frames. Runtime-dependent operations retain actual macOS15/iOS18/tvOS18/watchOS11 availability.

## Failure, Concurrency, and Constraints
PlanarContinuationError owns invalid input, capacity, malformed payload, stale binding, cancelled, nested physical and Runtime-code failures. Runtime bridges retain cause category and failed numerical-work availability. Caller maximum wire bytes plus grid metadata/cell bounds admit context before traversal; checked Int sums/products admit dynamic storage. PlanarContinuationWork.maxStorageBytes/maxWorkUnits are distinct from Runtime transaction and NumericalWork limits; validation units conservatively charge each visited byte and fixed scalar-check work, not CPU time. Provider maps RuntimeValidationBudget to these exact ledgers and reports actual peak/used units. Cancellation is checked at entry/metadata/rows/final publication. Model/grid migration is explicitly unsupported at its required callable branch with an incomplete marker; general moving-grid/FSI APIs are absent, not successful placeholders.

## Verification and Change Impact
Independent MAC vortex pressure/nonzero evolution and shear discrete amplification; exact full-state encode/decode; actual compiled static-root Runtime accept/reject/checkpoint/restart and same-build replay with caller RNG draws. Forged structurally valid bytes with stale context, NaN, gauge/divergence/time/sequence mismatches, truncation/extension and codec/Runtime/numerical budgets must fail while preserving the whole accepted owner. Real Cholesky iteration exhaustion propagates unknown failed work; actual successful solver followed by Mutex cancellation must refuse publication. A real-flow wrapper resets its numerical ledger only after the actual correct step, then returns or throws: zero/precharged incoming cases must restore the known ledger, propagate unavailable work, preserve the whole prefix/RNG and invoke exactly once. Changes to wire/binding/association invalidate continuation tests and root selected profiles; solver mathematics remains the projection owner's evidence.
