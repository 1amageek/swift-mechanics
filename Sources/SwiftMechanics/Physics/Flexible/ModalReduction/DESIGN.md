## Responsibilities and Boundaries
Construct pencils through published IM28 builder contracts from existing IM19 beam/Tet4 assembly. Generate modes through the published modal analyzer, independently check retained eigen-equations and mass Gram, and project the actual operators. Own maps, retained/truncated mode disclosure, source freeze, envelope admission, original linearized balance and virtual-power diagnostics. Do not generate a full flexible integrator, certify truncation error, modify materials/boundaries, or consume unqualified shell/Hex8/cable paths. Tet4 dynamics are increments about the supplied operating positions; supplied external efforts must be increments about an equilibrated operating load. The caller owns equilibrium certification and monotonically updates mesh revision for geometry/material/boundary changes.

## Architecture
```text
IM19 beam / validated Tet4 + fixed coordinates
  -> IM28 physical pencil -> complete physical eigensystem
  -> retained-index / mass-Gram / original-eigen-equation admission
  -> Phi^T M Phi, Phi^T K Phi, Phi^T C Phi, Phi^T B, H Phi
  -> implicit Euler via IM03 LU -> actual full and subspace balance
  -> zero-fixed full displacement/velocity, interface power, stress location
```

## Contracts and Invariants
All production records are immutable Sendable; arrays are row-major. A selected mass-normalized eigenvector is multiplied by `sqrt(energyScale)*timeScale`, giving Phi rows their source coordinate dimensions and dimensionless modal q. Mr has energy*time^2, Kr energy, Cr energy*time, and reduced efforts energy. Actual projected Gram is retained; it is never replaced by identity. Gram normalized by energyScale*timeScale^2 must meet the explicit identity tolerance, proving retained independence within that tolerance. Every retained eigenpair is checked against original M/K; all nonoscillatory neutral modes must be retained and any unstable mode rejects the selected stable-domain preparation.

Maps explicitly declare per-coefficient dimensions. B maps input efforts into source conjugate efforts; H maps source displacement into interface displacement. Interface load is H^T e and modal load is (H Phi)^T e. The numerical discrepancy between e dot H v and reduced-interface effort dot modal velocity is accepted separately. Zero fixed increments/velocities reconstruct into the original beam/nodal layout; original residual covers every unfixed equation, while fixed reactions are outside the frozen pencil. No zero residual is implied for eliminated constraints.

Preparation stores original pencil, complete eigenvalues, selected/truncated indices, source beam or full validated mesh/material/cell snapshot, maps and explicit envelope. Step checks the supplied current binding against the frozen binding; edits to retained modes, maps, source/material or fixed coordinates require a new model and initial state. The model is carried by the state, preventing state reuse with another reduction. Displacement/velocity/time/frequency/full-residual/reference-error limits are caller-declared operation policy, not proved truncation bounds. Excitation frequency must lie below the first omitted positive natural frequency. Full linearized residual is checked independently of its projected residual. Optional full-reference comparisons report instantaneous normalized displacement error only; absent reference yields no error certification. Neither residual certifies nonlinear accuracy, time discretization error, or unobserved states.

Tet4 reconstruction forms actual current edges from operating positions plus reconstructed increments and admits F through the frozen material's published FiniteStrainKinematics/StrainDomain contract. Inverted or excessive-strain reconstructions cannot publish an initial state or accepted step. This domain check does not certify frozen-tangent linearization error. Full-reference records carry source binding and exact endpoint time; mismatches reject comparison.

## Runtime Flows
Preparation consumes caller NumericalWork and, for Tet4, ConstitutiveCallWork. Step uses endpoint input/interface efforts and implicit Euler: v1=(q1-q0)/dt, a1=(v1-v0)/dt, (M/dt^2+C/dt+K)q1=f1+M(q0/dt^2+v0/dt)+C q0/dt. Outputs publish only after source/envelope, original/subspace force balance, reference comparison if supplied, power and cancellation checks.

The additive `tetrahedralStress` overload requires exact expected StructuralBinding, Tet4FieldLocation, explicit geometryRevision, FieldOutputPolicy and caller FieldConstitutiveWork. It reconstructs original full increments/velocities through the retained basis, adds increments to the exact frozen operating positions, and invokes the qualified field evaluator on that identified NodalState. The returned ModalTet4StressOutput retains modal state/binding, material-coordinate sample and aggregate caller NumericalWork. First-Piola/element-constant is explicit in the sample; all actual strain/stress/energy/force fields come from the assigned material evaluation, never the frozen tangent. Geometry revision is a caller-declared snapshot label; without a previous snapshot this operation claims no monotonic animation/history authority. Its source owner is newly created per query from the exact retained validated mesh, so no cross-query identity is inferred.

The old ConstitutiveCallWork signature remains marked typed unsupported. Its internal charge method cannot be used across the public component boundary. No supplier ledger is mutated to represent an unperformed assembly call, and the new overload never invokes the old signature or silently replaces its ledger. FieldConstitutiveWork charges exactly one actual evaluate per mesh cell including material failure; all mesh cells are evaluated before sampling the selected location. This is a bounded full-mesh query, not a one-cell-cost promise.

The operation reserves retained model/reconstruction and identified nodal inputs before allocations, then creates a supplier NumericalWork with the remaining budget and the simultaneous model/nodal reservation. Both field evaluation and sample share that real supplier work; success and typed supplier failure absorb it into caller work. The field policy retains its own field-output cap; global simultaneous storage is separately bounded by NumericalWork. Both modal and field cancellation gates apply; failure publishes no partial ModalTet4StressOutput and leaves consumed numerical/material-call work observable.

Beam stress evaluates the Hermite second derivative at explicit element coordinate and signed fiber distance, including frozen compressive axial stress. Beam slope and axial-plus-bending strain are bounded conservatively per element. The legacy Tet4 stress signature remains an explicit marked unsupported callable branch because its original constitutive ledger lacks public charging. The additive overload uses the qualified field publication contract described above; its selected modal stress composition now has the actual matching-source Native evidence below. Neither path derives stress from frozen-tangent dynamics.

## State, Ownership, and Lifecycle

## Failure, Concurrency, and Constraints
Checked count/byte/work arithmetic precedes allocation and traversal. Model snapshot, source mesh/beam, map metadata, matrix intermediates, solver reservation, retained result and live caller arrays are included conservatively. NumericalWork caps operations/iterations/scalar storage; policy caps source coordinates/maps/metadata. Cancellation is checked at row/cell boundaries and before publication. Typed failure keeps caller input state unchanged; consumed work remains observable. Nested structural errors preserve their original cause; failed IM03 supplier work is explicitly unavailable rather than guessed. No frequency shift, mode substitution, diagonal mass replacement, precision/backend fallback or regularization occurs.
