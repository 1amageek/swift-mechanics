# TopologyContinuation

## Purpose and Scope
Parent: [Mechanisms](../DESIGN.md). No children. Own bounded accepted subtree-release event history, exact target catalog migration, surviving scalar actuator history rebinding and atomic Runtime publication. Legacy one-event v1 remains a separate path; no v1 import API is declared.

## Responsibilities and Boundaries
Require a reconciled subtree transition and a source-bound explicit or supported scalar reaction observation. Own planned event rule catalog, monotonic event identity/time/global sequence/stamp chain and decodable bounded payload. Account for every source contributor exactly once and every target required schema exactly once. Runtime owns ticket/cancel/lifecycle gates, complete source comparison, RNG preservation and atomic model/configuration/handler/workspace publication. Integration/Actuation suppliers own their concrete payload semantics.

## Architecture
```text
source checkpoint + history + rule catalog + reconciled physical target
  -> source-bound observation + ordered history append
  -> per-source disposition: preserve / scalar actuator rebind / explicit integrator retirement+initialization / owned history append
  -> exact required target catalog + contextual target handler admission
  -> opaque prepared token -> RuntimeModelReplacement -> atomic publish
checkpoint bytes + explicit same catalog/target model -> bounded decode + complete history/catalog/physical-time/sequence validation -> fresh owner restart
```

## Contracts and Invariants
Fresh final owners may use an explicit immutable restore-only bootstrap: its empty history has the exact final model as initial stamp and sequence zero, and the handler binds the exact caller-declared compiled physical state. Only accepted sequence zero and the exact bootstrap record qualify. The saved-history branch decodes bounded bytes against the original catalog and final target, then validates the complete final supplier registry. Ordinary trials cannot advance bootstrap or replace saved history with an empty later prefix. Publication handlers never carry bootstrap authority.
Rule IDs are unique increasing caller IDs with explicit removed joint, connector/frame IDs, released root and metric/threshold. Explicit release has no inferred bearing reaction. Scalar force/impulse criteria bind the actual ConstrainedMotion source snapshot/time/velocity/layout and one-DOF original joint; force/torque and linear/angular impulse temporal meanings stay distinct. General bearing-wrench criteria are not declared by this owner.

History retains ordered events: unique increasing IDs, nondecreasing accepted time, strictly increasing global accepted sequence, exact source→target stamp chain and source+1 revisions. Same-time cuts differ by global sequence. Every historical removed joint is absent and retained virtual connector is present with the declared root/child/frames/sixDOF meaning. Payload binds the exact rule catalog and initial stamp/time/sequence, with bounded strict UTF8, lengths, counts, finite values and no trailing data. Contextual admission checks history is not ahead of physical time/global sequence and binds the exact target descriptor and configured complete provider catalog.

Surviving actuator migration decodes actual fixed-codec source state, proves unchanged joint ID/manifold/anchors/authority and source/target range mapping, creates new model/index binding with identical lawRevision/continuationKey/domain/frame/kind, encodes and decodes the target state exactly and requires ActuatorRuntimeContributors validation. Time/primary/secondary/mode/sequence are preserved. Callbacks keep original ActuationWork bounds and monotonic counters with a nonzero seed; unavailable failed work remains explicit. Removed-joint actuators, unsupported Hybrid/Sleep or other law migration are typed failures. Preserve requires target required validation; generic supplier declarations are not physical migration certificates.

Explicit integration initialization names the retired source integrator and exact target provider/equation, generates initialRecord for reconciled physical q/v/time and checks associatedHistory. Integration sequence reset is explicit. No source record is omitted, duplicated or silently replaced. A target schema/record omission fails before publication. Prepared construction uses an immutable admission token issued only after full source/generation/history/catalog/physical admission, with fileprivate issuance authority.

## Runtime Flows
Preparation and all supplier validation run outside Runtime locks. Publication uses the required RuntimeModelReplacing.snapshot witness to check the retained accepted state, then passes its complete checkpoint as expectedSource to the required replaceModel witness. Runtime replacement rechecks the exact source under its operation lease and owns invariant capacity/continuation/determinism, accepted time, newer model revision, RNG and accepted sequence. The preparer retains topology-specific source/history/catalog/physical proof; its sourceConfiguration is preparation metadata, not a configuration introspection requirement on the Runtime protocol. A changed source, duplicate event, stale history/catalog, unknown law, over-capacity input or cancellation preserves the entire accepted prefix and RNG. Replay from an earlier revision uses a fresh owner of that revision and deterministic reapplication; final-target restart uses an explicit final model/catalog/provider.

## State, Ownership, and Lifecycle
Catalogs/providers/histories/prepared values are immutable Sendable owners. Byte parsing, trial law state and all work ledgers are exclusive operation-local values. No global state, raw pointer view, unsafe isolation or target-conditioned storage is added.

## Failure, Concurrency, and Constraints
Caller policy owns maximum events, bytes, metadata and validation work/scratch. All counts/lengths and arithmetic overflow are checked before allocation. Required supplier validation receives explicit remaining budgets and its evidence is bounded. Unknown/replaced opaque ledgers stop without retry. Legacy v1 import, general loops, prescribed Runtime checkpoints and unsupported supplier topology migration remain explicit gaps.

### AF26 selected sleep retirement publication (DESIGN ONLY)
[SleepContinuation](../SleepContinuation/DESIGN.md#af26-selected-topology-wake-consumer-contract-design-only) owns source sleep admission, opaque retirement issuance and exact source-law disposition. This owner consumes that token with the same real `SubtreeRelease`, a lower-issued retained-row quadratic physical acceptance, source topology history and source-bound explicit rule observation. It adds a specifically named retirement disposition; generic preserve remains unable to carry old sleep authority. All source contributors must still have exactly one declared disposition, and target required schemas must match all produced records/providers exactly.

The planned `TopologyContributorDisposition.retireSleep` consumes an owner-issued retirement token and replaces the old sleep record with a bounded `SleepTopologyWakeContributor` event. The event binds exact admitted source/target model and law identities, original sleep record/history and source q/v/time/global sequence, cut joint/connector and release rule ID, retired row/effort identities, retained mapping and target reconciled physical authority. Wake applies to the complete mechanism; the target registry has no sleeping omission authority. The event accepted time equals the source time; its global sequence is S+1, equal to the topology event and Runtime replacement. It preserves the original command/wake provenance as retired evidence rather than inventing new command generations. Its immutable catalog is reconstructable from explicitly supplied original source and final target owners; stale law/mass/policy, malformed/truncated/over-capacity payload, missing retirement or different release identity fail before publication. The new event schema is additive, and legacy sleep payload kinds/flags are unchanged.

Root registers this owner's actual topology history provider through Sleep's additional RuntimeContributorHandling contract alongside sleep/integration from session creation. Sleep consumes its public Runtime schemas/validation only; topology history/event association belongs here. Dependency direction is SubtreeTransitions/Runtime -> Sleep retirement -> Topology publication, with lower nonlinear reconciliation/admission also consumed by Topology. Root owns the registration and equation/evolution composition; no production dependency points back from Sleep to Topology. Thus the existing `appendHistory` disposition consumes a real source record. New target catalog consists of appended topology history, sleep topology wake event, the real target integration provider and any explicitly admitted unrelated surviving contributors. Unknown laws and unsupported histories remain failures; this selected path does not expand actuator/Hybrid/loaded migration.

Planned `SleepTopologyTransitionPreparing.prepare` accepts source/configuration, actual release, owner-issued retirement, the lower issued quadratic target acceptance, history/observation/rule, explicit contributor dispositions, target equation/continuation/contextual handler inputs and caller work; it returns `PreparedSleepTopologyPublication` or original typed preparation failure. Its `publish` requirement consumes that prepared value and `any RuntimeModelReplacing`. The selected history-append overload consumes the exact real release and lower accepted target rather than forging the old free token. Before selecting the reconciled acceleration, preparation compares the acceptance's exact target model/descriptor/layout and revision to `release.target`, and its q/v/time to `release.incomingPhysical`; drive and retained-row law must equal the retirement derivation. Only acceleration is reconciled by the real lower producer. A different source, chart, target law, physical coordinate or issued token is rejected. The lower design owns the acceptance type, issuance and original-force proof; no lower sealed token is minted or updated here.

Target history initialization uses existing public `IntegrationContinuationProvider.initialRecord`, `history`, `record(acceptedTime:point:nextStep:acceptedSteps:normalizedError:)` and `associatedHistory`. It explicitly retires the old chart, reads the genuine target equation at reconciled q/v/time, resets step/error state to configured RK4 initialization and encodes the actual global accepted sequence S+1. This sequence is an accepted topology boundary, not a fabricated integration step. The target record is re-associated with physical source/time and the new contextual handler's sequence rule. No shared Integration writer change is required. Existing `initializeIntegration` sequence-zero reset behavior is preserved; an additive selected initialization operation/disposition owns global association.

Existing `PreparedTopologyPublication` and its `handler: TopologyCheckpointHandler` API remain unchanged for the original free-reconciled release path. An additive `PreparedSleepTopologyPublication` holds the real release, owner-issued retirement, lower-issued retained-row quadratic physical acceptance, `handler: TopologyCheckpointHandler` for history/catalog consumers and `checkpoints: any RuntimeCheckpointHandling` for actual target admission/publication. Its separate selected prepare/publish protocol requirements consume that physical authority; they never forge or rewrite ReconciledSubtreeRelease. Selected sleep retirement wraps the complete target handler with the lower genuine quadratic contextual handler; target preparation and publication use this same handler and actual accepted physical output. Its private publication admission token is issued only after full candidate admission and exact result comparison. The original free acceleration preparer cannot supply this coupled physical result: M*a=drive alone gives B=-2/C=0, whereas retained-row acceptance requires constraint reaction and B=C=-1. No arbitrary injected handler can replace that physical proof. The lower quadratic handler is a prerequisite whose authority/evidence are owned by NonlinearEvolution; its public contract must be qualified before production dispatch.
