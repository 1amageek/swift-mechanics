# Stationary Island Dynamics

## Purpose and Scope

This child owns compiler-issued structural islands and source-bound original physical motion/rest evidence for mixed sleep. Parent: [Mechanisms](../DESIGN.md). No children. The selected source is a fixed static spatial root with directly attached dynamic scalar revolute/prismatic branches, fixed anchors, zero external loads and immutable generalized drives, with stationary affine retained rows. It is the serial physical prerequisite of IslandSleepContinuation; it neither owns accepted state nor publishes contact, sleep, event, Integration, Runtime or RNG state.

## Responsibilities and Boundaries

Own complete branch/coordinate/row partitioning, genuine island compilation, exact public source mappings, canonical physical-law binding, original per-island dynamics and force/rest acceptance. Preserve every original body, inertia, joint, anchor, coordinate dimension/scale/domain and retained row in its responsible island. Never flatten another graph, invent constraints, copy a mass submatrix into a producer handle, or treat one sampled cross-mass zero as a stationary law. Compiler and physical suppliers remain read-only qualified dependencies. General trees, prescribed/floating/planar charts, time-dependent/nonlinear rows, external loads, semantic extensions and cross-island physical dependencies require a separate authority and fail explicitly.

## Architecture

```text
whole compiled source + exact rows/drives/policies
  -> bounded direct-branch and row-support admission
  -> public island tree layouts -> exact source coordinate mapping
  -> original compiler with copied original records -> immutable program
accepted physical q/v/time -> actual mapped compiled state/snapshot
  -> rigid assembly -> real forward OR retained-row acceleration
  -> original source/force/row/energy checks -> immutable motion/rest proof
```

## Contracts and Invariants

Public protocol `StationaryIslandPreparing: Sendable` has `prepare(source: CompiledMechanicalModel, constraints: QuadraticConstraintSystem, drive: [Double], policy: StationaryIslandPolicy, work: inout StationaryIslandWork) throws(StationaryIslandFailure) -> StationaryIslandProgram`. `ReferenceStationaryIslandPreparer` injects `any MechanicalModelCompiling`; there is no alternate mass/system constructor. The policy contains caller island/signature/identifier/compilation-call limits, original MechanismSolvePolicy and DynamicsAdmission. Source CompilationPolicy is consumed unchanged. Cancellation sources remain live nonserialized operation policy, not persistent physics.

`StationaryIslandProgram` and its `StationaryMechanicalIsland` entries are immutable Sendable references with internal issuance. Public read-only facts include original source/constraints/drive, canonical binding, stable island ID, actual compiled model, original coordinate indices/IDs and retained row IDs. Binding losslessly includes the actual full source descriptor, compiler physical/chart policy, source coordinate/time domains, complete original row coefficients, drives and all numerical physical acceptance policy fields. Same model stamp/layout with altered mass, anchor, drive, row or policy cannot restore another program's history. Persistent signatures are canonical exact scalar bits; a digest or caller-supplied signature cannot replace physical equality.

Each nonroot body is one original dynamic scalar joint child directly attached to the same static fixed root. Anchors are fixed, and no descendant or prescribed authority is admitted. Physical body/inertia and world/root frame records are identical to the original; island root reuse denotes the same immobile boundary, not another dynamic body. Source features/extensions/representation requirements are admitted only when their exact disposition is supported; initially nonempty such obligations are rejected rather than filtered. Every source scalar appears exactly once. Nonzero retained-row supports connect branches into islands; zero coefficients do not change original row values and are preserved. Rows with no genuine support or ambiguous/dependent allocation cannot issue the selected full-rank evidence.

Build each island's actual public KinematicTree from original body/joint records first, then resolve its coordinate ranges by joint ID against the original tree. This establishes the island initial q/v/a in the compiler's actual layout order before compilation; descriptor order is not state order. The original compiler receives a real descriptor containing the static root and selected original branches, mapped original initial state, unchanged root/world/revision and the source compilation policy. Its result descriptor/policy/tree/layout and initial body/anchor/column association are checked against that construction. Island identities are bounded, distinct derived identities; their stamp alone is not proof of correspondence.

Structural direct-branch independence proves the physical partition for all admitted q/v, because branches share only an immobile root and immutable internal force/row ownership. At physical admission, actual whole and island snapshots verify retained body pose/motion, geometric velocity columns, frames, time and mapped q/v; genuine whole original assembly verifies mass/bias/drive/row correspondence when issuing or cold revalidating a proof. No partition is inferred only from one instantaneous matrix. All whole source rows remain represented once, with original normalized coefficients/scales and physical unit conversions preserved.

`StationaryIslandComputing: Sendable` requirements are `motion(program: StationaryIslandProgram, islandID: UInt64, physical: KinematicState, work: inout StationaryIslandWork) throws(StationaryIslandFailure) -> StationaryIslandMotion` and `certifyRest(program: StationaryIslandProgram, islandID: UInt64, physical: KinematicState, thresholds: MechanismSleepPolicy, work: inout StationaryIslandWork) throws(StationaryIslandFailure) -> StationaryIslandRestCertificate?`. `ReferenceStationaryIslandDynamics` injects public rigid equation/dynamics, constraint evaluation/rank and constrained solver requirements. Nonempty islands use actual stationary affine samples plus the original constrained acceleration solve; an actually row-free island calls original forward dynamics directly. The empty set is not converted to an artificial constraint.

Motion evidence retains original whole physical source and immutable program/island binding, mapped actual snapshot/velocity, acceleration, original force/reaction and kinetic evidence. Original M*a+bias=drive+forces+reaction, q/v row consistency, acceleration row residual, source/time/meaning and finite output are independently accepted under original policies. Rest certification additionally requires exact island v=0 and accepted acceleration=0, positive physical mass and the actual declared energy/normalized-velocity criteria. Other islands may have nonzero velocity. A nonresting island returns nil only after genuine admitted physical evaluation; supplier failure is never nil. A certificate captures island q, drive, immutable source/law/island identity and validity domain; structural independence makes unchanged island q/v a stationary equilibrium despite other islands' motion. It does not confer dwell, accepted sequence or event authority.

The same computing protocol requires `associateRest(certificate: StationaryIslandRestCertificate, program: StationaryIslandProgram, physical: KinematicState, work: inout StationaryIslandWork) throws(StationaryIslandFailure) -> Bool`. This is the lower-owned bounded re-association of an issued stationary certificate to current exact island q/v/time/program law; it does not repeat physical suppliers or grant history authority. Other-island q/v may differ only through the already proved structural independence. Changed island q, drive/program binding, nonzero island v or a time outside the certified original domain returns false. A well-formed certificate from another valid canonical program returns false. Malformed physical shape/revision/prescribed state, nonfinite state, invalid certificate island/position correspondence, or failed work admission throws. Time-domain rejection is a false association predicate, not malformed source. Upper caches consume this requirement and do not reconstruct lower private proof predicates.

## Runtime Flows

Capacity/source admission -> structural partition -> genuine island compile -> exact mapping -> original whole/island correspondence -> immutable program. Physical operation -> map actual source -> real state/snapshot -> noninline assembly -> real free/constrained solve -> original association/acceptance -> immutable evidence. Compilation, snapshot, assembly, solve and publication are separate noninline phases with bounded immutable reference contexts; future rich failure/output temporaries must not overlap nested suppliers at the original 128 KiB profile.

## State, Ownership, and Lifecycle

Program, island and evidence owners are immutable Sendable references. No mutable current physical source, persistent selection, global cache or implicit history exists. Numerical/load ledgers are exclusive operation-local values. Any callback receipt introduced to bridge public numerical boundaries uses the same Mutex storage/read/write/isolation on Native/WASM/Embedded, and callbacks execute outside the lock. Original supplier/model owners remain retained through their synchronous operation; no pointer or view escapes. Cold restoration reissues actual physical proof in a fresh owner, independent of memo warmth.

## Failure, Concurrency, and Constraints

`StationaryIslandFailure` preserves a typed reason, exact known `StationaryIslandWork` receipt and unavailable-work classification. Reasons distinguish original CompilationFailure/DynamicsError/ConstraintError/MechanismError/NumericalError/LoadError, unsupported structural law, source/mapping mismatch, rank ambiguity, capacity/overflow, cancellation and supplier-ledger breach. Rich supplier cases use compact immutable indirect storage; original errors are not stringified or replaced. Cancellation remains the primary original cause when ledger corruption also occurs, including cancellation nested in Dynamics loads/numerical or Constraint numerical/linear/nonlinear failures. Unknown supplier work flags from original Constraint and Dynamics reports propagate to both the failure and its exact operation-local work receipt. No opaque failed call is retried.

`StationaryIslandWork` contains actual NumericalWork and LoadWork separately plus bounded compiler invocation count and unavailable flag. Compiler has no public caller arithmetic report: invocation count and admitted CompilationPolicy bound it, without claiming hidden compiler arithmetic as NumericalWork. Throwing opaque compile/kinematics work is unavailable, while all known owner/physical prefixes remain reported. Owner setup/mapping/encoding costs are charged before traversal/allocation; physical callbacks receive nonzero admission quantum and known ledger snapshots, checked for unchanged budgets and monotonic counters/storage on both outcomes. Reset restores only the known prefix. Load receipt reconstruction reinstates the original live cancellation closure. If cancellation prevents reconstruction after the callback, restore the original-budget known pre-call load prefix, retain the original supplier cause when present, classify the unrepresentable suffix as unavailable, and never retry. Numerical work actually returned with a valid monotonic receipt is still merged. Source storage is reserved separately from lower workspace; child constrained outer/dynamics/rank/linear work receives disjoint one-quarter remaining counter/storage allowances and is admitted and truthfully merged without changing unit. No LoadWork is converted to numerical count.

For B source bodies, n scalar coordinates, m rows and I islands: I<=n; branch graph and original row support traversal are bounded by B+n+m*n, each row Hessian representation by n*n, signature by caller maximumSignatureBytes, and I actual compiler invocations by maximumCompilationCalls. All counts/products/sums/identity lengths are checked before work/allocation. Island numerical workspace derives from each admitted dimension and original producer capacities; whole correspondence includes bounded original n*n assembly. Admission/cold proof cost is separate from repeated stage motion cost. Actual root/island body reuse, local workspace and signature bytes are included in declared live storage. No wall-time or allocator speed claim follows from these bounds.

## Verification and Change Impact

The dedicated tests must prove genuinely compiled mass2 Z-rotor A/B with gear row [1,1,0] and independent mass2 Y-striker C, actual source layout including non-tree descriptor order, source columns/mass/force correspondence, A/B rest with moving C, genuine row-free C motion and genuine constrained awake A/B. Independent whole-vs-island original physical outputs, changed mass/drive/anchor/row/policy refusal, non-direct graph refusal, incomplete coordinate/row mapping, rank/capacity/cancel and every supplier reset/failure prefix falsify the contract. Upper omission/wake/Runtime/global history is not qualified by these tests. Changes to this authority invalidate direct IslandSleep consumer assumptions and ConstrainedSleep event acceptance; frozen supplier internals are not modified.
