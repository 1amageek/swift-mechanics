## Architecture
```text
identified selected Tet4 + physical nodal field + calibration/sample ledger
 -> public reference/current geometry and source/layout gates
 -> affine p(x) reconstruction
 -> rigid-plane section OR pB-pA=0 section clipped to Tet4 B
 -> oriented convex polygon -> fan triangles
 -> exact degree-two pressure / position / shape / velocity integrals
 -> nodal resultant, moment, virtual-power + equal-pressure residual gates
 -> immutable patch/result with original selected sources and work
```

## Contracts and Invariants
Inputs retain expected model/mesh/pressure revisions, full mesh source, selected cell ID, sample identity and SI sample time, and a calibration record with source identity/revision and declared `suppliedPhysicalNodalPressure` fidelity. Calibration is attributable input rather than a verified constitutive law. Both field inputs must declare the same sample identity/time and common frame; a rigid-plane wrapper declares its expected plane revision and the same sample. No same-time provenance is invented. Material ID/source, cell source, node IDs, and original field values remain reachable through retained immutable inputs in the result.

For current edges D and public reference inverse D0^-1, det(D D0^-1) must exceed policy.minimumVolumeRatio. Current inverse supplies shape coordinates N(x). For pressure values pi, p(x)=p0+g dot (x-x0), with g=D^-T (p1-p0,p2-p0,p3-p0). Rigid-plane normal is supplied and unit checked. For two fields, h=pB-pA and the interface normal is normalized grad(h), pointing toward the partner for inward-increasing physical pressure fields, with force -p*n on A and +p*n on B. This convention is explicit and body-order covariant; users must supply pressure fields consistent with the selected compliant representation. The interface is the zero set within both closed selected current volumes. Intersections with a Tet4 vertex/edge/face within tolerance are typed unsupported degeneracy, rather than an arbitrary duplicate face owner. Coincident pressure fields with volumetric equality fail as ambiguous; separated parallel pressure planes return a physically absent patch.

Cut the six A edges, cyclically order their 3/4 intersections in the interface plane, then clip against B's four current barycentric halfspaces using Sutherland-Hodgman. At most eight vertices and six triangles are retained (a plane intersecting two tetrahedra has at most eight polygon sides). Clipping tolerance classifies near-boundary cases as degeneracy; no snapping moves an interface or invents pressure. Plane cuts outside the selected volume and clipped empty intersections are legitimate absent-contact results after admission.

For affine y and p on an oriented triangle of area A: integral(p)=A*sum(p)/3 and integral(y*p)=A*((sum(y))*(sum(p))+sum(y*p))/12. This integrates position, each Tet shape function, and interpolated velocity exactly. Three symmetric degree-two quadrature points independently evaluate p, N, x and velocity for the original geometry/equal-pressure and surface power checks. Integration rejects negative/out-of-range pressure. Each side's assembled nodal force/resultant/moment/power is compared with the original surface integrals using caller scales; two-body nodal action-reaction is also checked directly. Rigid power uses the actual supplied twist about its declared point and moment transport, and is accepted against independent quadrature of v(x)=v(point)+omega cross (x-point). Total power may be nonzero for supplied-pressure contact; no passivity, potential, equilibrium, force-to-impulse, or accepted dynamic response claim follows.

Capacity/metadata budget and cancellation -> each original layout/source/cell gate -> reconstruct -> cut/clip -> exact triangle integration and independent quadrature checks -> original residual acceptance -> final cancellation -> atomic immutable publication. Supplier failures retain original CoreError/NumericalError; no retries or hidden supplier work occurs.

## Failure, Concurrency, and Constraints
Policy owns maximum nodes/cells/materials/metadata bytes/vertices/triangles/pressure, inversion/inverse/area/geometry/pressure/residual tolerances and physical residual scales; all finite positive ranges are validated. NumericalWork charges arithmetic, metadata traversal, source comparison, and bounded loops. Checked products/sums precede buffer reserve; fixed-sized matrix calls have declared conservative logical operation charges. Source/calibration/sample mismatch, missing field, invalid layout/material/frame, inversion, ambiguous equal-volume pressure, boundary degeneracy, nonfinite pressure/result, capacity, cancellation and numerical/core failure are typed. Unsupported whole-mesh automatic discovery, arbitrary surfaces, friction/laws and evolution have immediate incomplete markers and typed refusal.
