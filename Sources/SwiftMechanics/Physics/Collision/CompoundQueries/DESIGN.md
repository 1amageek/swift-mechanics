# Compound collision child aggregation

## Purpose and Scope
Parent: [Collision](../DESIGN.md). Owns the selected CL-002 rigid compound of identified analytic sphere/box/half-space child proxies. Children: none. The service computes closest allowed child pair, all child overlaps, and ordered child ray hits. This is geometric aggregation, not a contact response or union surface solver. Selected AF35.30 implementation; behavioral qualification is owned by [CompoundQueriesQualification](../../../../../Verification/CompoundQueriesQualification/DESIGN.md), with root-owned registration and integration.

## Responsibilities and Boundaries
A compound producer owns immutable child inventory, source manifest, revision, common local frame and one body. A placement owns the local-to-query transform and query frame revision. Original child collision representation, provenance, shape, margin, geometry revision, resolution and filter remain authoritative. The manifest provenance identifies the assembly and does not certify individual sources. The caller owns authentic revisions and advances the assembly revision whenever children, local frame, filter or assembly semantics change. Caller-selected expected revision must match at placement admission. Placement admission rechecks the supplied policy against retained child count/metadata and charges its additional destination-frame UTF8 metadata before publishing. No implicit source lookup, conversion, default child geometry, nested compounds, meshes, deformation, or manifold is provided.

## Architecture
```text
original proxies + SI unit + local frame/body/source/revision
 -> bounded CompoundCollisionShape admission (ID ordered)
 -> expected-revision CompoundCollisionPlacement
 -> checked Core pose composition + public CollisionProxy reconstruction
 -> injected qualified CollisionGeometryQuerying
 -> original child witness / ray hit + two-level identity attribution
```

## Contracts and Invariants
Children are nonempty, distinct collider IDs, distinct from assembly collider ID, and share the declared body/local frame/revision. Cross-compound child IDs and assembly IDs must be distinct, including child versus the other assembly ID. Revisions are opaque caller-owned UInt64 values; zero is not invented as invalid. Length units must have length dimension, scale exactly 1 and offset 0; no conversion is performed. All child representation/source/ID/unit-symbol metadata is UTF8 byte bounded and charged before publication. Each child is a public validated CollisionProxy. Core finite vectors and unit rotations validate transforms; composition failures propagate.

Pair filters run assembly enabled/layer-mask, then child enabled/layer-mask, joint exclusion and same-body policy. Custom user filters are explicitly unsupported for this selected compound contract. Exclusion key UTF8 traversal is charged before identity comparison. Joint exclusions must reference two actual children across the supplied inventory, including when another filter rejects them; duplicate exclusions fail. The lower user-filter failure API carries no consumed-operation receipt. A nonnil user filter is therefore refused before dispatch with unsupportedUserFilterAccounting after structural/exclusion admission, independent of earlier disabled/mask decisions. No callback executes and no unknown callback work is invented. Supporting custom callbacks requires a qualified failure-consumption receipt contract and independent failure accounting evidence. Triggers retain original child flags in child proxies and assembly flags in placements; no trigger events are invented. Ray queries apply assembly and child enabled flags, matching the lower scene query contract. All children are quality-validated before query dispatch, even disabled children, to reject an invalid requested fidelity domain transactionally.

Closest returns the minimum signed separation over allowed child pairs, ties by first then second child ID. Nil means no allowed pair, never unsupported pair. This value is a proximity/deepest child penetration selector, not compound minimum translation distance. Overlap returns all allowed original child witnesses with separation <= 0 in lexicographic first/second child ID order. No deduplication or feature remapping occurs. Ray hits retain original child boundaries, including interior boundaries of overlapping children, ordered by distance then child ID. No union entry/exit claim is made. Approximation error is the original per-pair sum or per-hit child bound; no invented assembly accuracy guarantee. Wrappers retain assembly identity/provenance/revision, original local child proxy and world child witness identity/pose.

## Runtime Flows
Every operation checks cancellation, admits query frame compatibility/cross-IDs/exclusions, prepares transformed immutable children, then traverses the complete selected inventory. Geometry and filter errors retain causal child IDs and original typed errors. Results stage locally and publish only after final cancellation check. Closest must finish all allowed pairs before returning its best value. No retry, truncation or fallback exists.

## State, Ownership, and Lifecycle
All producer, placement, result and service values are immutable Sendable. Mutable arrays and counters exist only in the exclusive operation or caller inout CollisionWork. Arrays retain their original value storage and strings; child pose reconstruction creates only required world proxies. No unsafe pointer, borrowed view, shared mutable state or target conditional exists. The same ownership and Sendable contracts apply Native/WASM/Embedded; no Mutex is required for immutable service storage. Injected geometry service must satisfy its published Sendable, work and result contracts.

## Failure, Concurrency, and Constraints
CompoundCollisionPolicy bounds children per assembly and UTF8 metadata bytes. CollisionWork bounds cumulative operations, record caps and peak scalar slots with checked arithmetic; all charges already incurred survive failure. Admission is O(n²) ID validation and insertion ordering. Pair operations are O(n*m + exclusions*(n+m) + exclusions²); rays O(n + hit insertion). Fixed analytic scratch is reserved together with retained transformed inputs and staged outputs, so lower requireStorage calls cannot understate combined peak. Output record cap checks precede append; scalar slots cover complete retained records conservatively. Caller-owned input metadata has a separate byte cap. No guessed limits/defaults are installed. Unsupported lower pairs/rays fail rather than silently omitting children. Mechanical motion is supplied only through current rigid placement, with no dynamics/static-concavity restriction inferred from a geometric query.
