## Purpose and Scope
Parent: [Collision](../DESIGN.md). Children: none. A grid is an open surface, not a closed solid. Signed solid distance and dynamic concave response are explicitly unavailable.

## Responsibilities and Boundaries
Caller supplies row-major finite heights in meters, local origin, positive X/Y spacings, one uniform diagonal policy, collision representation, collider/body/frame IDs, source/frame/geometry revisions and rigid pose. Vertices are actual `(origin.x + column*dx, origin.y + row*dy, origin.z + height)` values. Each cell has two upward oriented original triangles; no bilinear patch or display LOD is substituted. Caller owns source accuracy and kinematics authenticity. This child owns geometry/witness identities; it does not install contact laws, broad phase, material response, time integration or CAD authority. Only qualified Core/Model/Collision contracts are consumed; new TriangleMeshes/ConvexQueries are not suppliers.

## Architecture
```text
identified grid + collision representation + revision + pose
 -> checked dimensions / coordinate distinctness / triangle rank / measured edge resolution
 -> immutable original grid and vertices
 -> every cell / both original triangles
 -> closest constrained projection | plane/barycentric ray | sphere distance threshold
 -> original reconstruction / KKT / normal / ray or sphere balance gates
 -> immutable owned witness with original grid feature

new heights + newer source and geometry revision
 -> same topology admission -> new immutable snapshot
```

## Contracts and Invariants
At least two rows/columns, exactly rows*columns samples, finite strictly increasing represented coordinates and numerically rank-two triangles are required. Uniform diagonal selects either lower-left to upper-right or lower-right to upper-left. Triangle IDs are `(row,column,half)` in row-major order; vertices retain original flat grid indices and edges retain sorted original endpoint indices. Original identity includes all heights, layout, representation and revisions; a revision number alone does not certify geometry equality. The measured maximum original triangle edge length records contact resolution, independently of display data. Query policy rejects source approximation deviation or measured edge spacing above caller limits. Approximation bounds describe the supplied proxy's relationship to its source, not numerical query residuals.

Distance is always unsigned to the exact supplied triangle set. For nonzero distance normal points from the selected surface point toward the query. At zero distance it is the selected original upward face normal; this convention is reported, including at seams. An oriented surface normal is also retained. Closest selection uses strict computed minimum and exact equality ties, choosing the first `(row,column,half)`; no tolerance-based farther face replaces the minimum. Exact tie count is reported. Each triangle's minimum is obtained from its feasible plane projection and all three finite segment minima. Barycentric reconstruction, nonnegative weights, original distance balance, unit normal and the original convex-triangle KKT inequalities must pass caller tolerances. A scale-normalized Gram determinant threshold `128*Double.ulpOfOne` refuses numerically rank-deficient geometry instead of inferring convergence.

Rays use qualified unit direction and a finite meter interval. Every original triangle is examined. Nonparallel candidates use plane intersection and original barycentric membership. Coplanar rays use affine barycentric interval clipping and return the first point of the closed triangle interval. Boundary origin returns distance zero. Both faces are visible, regardless of ray direction. Strict nearer parameter wins; exact ties use row-major triangle order. Near-negative barycentrics, unresolved plane bands or interval endpoint uncertainty fail explicitly, rather than causing a false miss. Every floating miss additionally requires outward interval arithmetic on original vertex plane/barycentric equations: same-sign endpoint plane intervals, a root interval outside the ray, or a barycentric coordinate excluded from its necessary closed range `[0,1]` everywhere. Each original barycentric coordinate is affine in the ray parameter, so its extrema over the closed candidate parameter interval occur at endpoints. Both endpoints are independently evaluated with outward original-vertex arithmetic; the maximum of their upper bounds excludes the entire interval when negative, and the minimum of their lower bounds excludes it when greater than one. The upper restriction follows from nonnegative coordinates summing to one; it does not introduce a tolerance or new geometry. This retains correlations lost by a Cartesian box around the whole ray. Otherwise it is `ambiguousRay`. Arithmetic overflow in that certificate also fails. Original ray-point and triangle-point residuals are checked before returning a hit. `nil` follows actual rejection of every original face; an empty candidate list is not authority.

Sphere overlap accepts only existing sphere proxies with the same frame ID/revision, explicit quality, and effective radius = radius + margin. The pair's summed source deviation must fit the query maximum. It compares the global original surface distance to that radius. Result kind is separated / boundary touching / surface intersection. Separation is distance-minus-radius; it is a ball/surface clearance, not a signed solid distance or penetration depth. Surface point, sphere boundary point, normal and original balance are retained. Nonzero clearance within the numerical length band fails ambiguous classification; exact equality is boundary touching. Negative clearance reports surface intersection only. No-hit/false overlap results require a completed all-face closest query. Other supplied shapes have an immediate incomplete marker and typed refusal.

Static surfaces, caller-prescribed rigid snapshots and discrete deforming snapshots are admitted. A snapshot query is instantaneous; motion mode does not grant dynamics or continuous moving-surface validity. Only deforming snapshots permit height refit, requiring unchanged topology/layout/IDs/frame meaning and strictly newer source and geometry revisions with the same source key. A rigid move preserves geometry and frame meaning; static surfaces reject moves. Queries require an explicit expected collider/frame/source/geometry reference, rejecting stale or incompatible use. No wall, underside or outside-footprint solid is invented. Signed-solid distance is a callable marked refusal until a separately certified closed-volume domain exists.

## Runtime Flows
Admission validates representation before array growth; reserves conservative live scalar/record storage; walks every height, coordinate and triangle. Queries validate expected reference, fidelity and work before full-face traversal. Refit reruns admission and produces a new owner. Any finite arithmetic, residual, ambiguity, cancellation or budget failure returns no successful partial witness. Work is cumulative caller-owned inout state and is not reset by operations.

## State, Ownership, and Lifecycle
All public geometry, policies, references and results are immutable Sendable values. Grid heights and generated vertices use retained CoW arrays; result identity retains original storage without borrowed pointers. Query workspace is fixed-size and exclusively local. There are no shared mutable caches, callbacks, I/O, pointer storage or async resources. Native/WASM/Embedded use identical storage and Sendable contracts; no target-conditioned isolation exists.

## Failure, Concurrency, and Constraints
Typed failures distinguish supplier Core/Model/Collision failures, invalid grid/identity/motion, stale source/reference, quality/resolution mismatch, degenerate triangles, unsupported signed solid/shape, ambiguous ray/overlap and original residual rejection. Dimension/index/count arithmetic is checked before products or allocation; dimensions must be exactly representable as Double integers. Conservative storage is `512 + 16*vertexCount` scalar slots and `16 + 2*vertexCount` records, covering input heights, generated vertices, refit staging and fixed query workspace. Each vertex/cell/triangle step charges work and cancellation; all-face admission/query complexity is O(rows*columns), without a guessed acceleration cap. Source identity strings and existing supplied representation storage remain caller-owned inputs. Measured edge length is computed on every original triangle, not inferred from horizontal spacing alone.
