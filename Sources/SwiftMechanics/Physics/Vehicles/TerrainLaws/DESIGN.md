# Calibrated fixed-patch deformable terrain

## Purpose and Scope
Parent: [Vehicles](../DESIGN.md). Children: none. Own AF35.4's selected EX-002 soil constitutive operator, exact rectangular footprint/cell overlap, sealed immutable trial/accepted history and checkpoint. Selected Native behavior is now evidenced by the [VehicleLawsQualification owner](../../../../../Verification/VehicleLawsQualification/DESIGN.md#fresh-af36-native-evidence); root owns shared registration. Ordinary WASM/Embedded and broader domains remain unqualified. This is a fixed Eulerian contact-patch model with homogeneous prescribed interface material velocity, not a translating rigid wheel/plate, moving footprint, bulldozing, granular solver or vehicle assembly. Contact material can pass through the fixed patch. No TireLaws dependency.

## Responsibilities and Boundaries
Caller supplies actual regular-grid heights, calibration provenance and parameters, initial unloaded interface height, physical body/terrain/material/frame references, prescribed homogeneous velocities and dimensional acceptance policy. The component owns cell-subarea histories and constitutive force/work; it does not solve interface motion or infer soil parameters. Grid transforms describe the supplied step geometry in a common reference frame; velocity drift is supplied separately. Angular interface/terrain motion and spatial velocity gradients are outside this selected operator.

## Architecture
```text
explicit grid heights + fitted soil coefficients + fixed rectangle
    -> exact grid-cell intersections and virgin subarea history
accepted history + interval velocity/dt/current references
    -> local elastic/Bekker return and Janosi shear integration
    -> world force/moment and original interface-work/energy checks
    -> sealed trial -> explicit accept against unchanged base -> new accepted history
accepted history -> checkpoint -> exact current-source restore -> same accepted history
```

## Contracts and Invariants
SI: grid positions/heights/width/sinkage/shear travel m; velocity m/s; time s; pressure/cohesion Pa; force N; moment N*m; energy J. Local x/y span rectangular grid cells, local z points upward. Quaternion maps terrain axes into reference axes. Cells are row-major rectangular columns/rows; all undeformed heights are supplied explicitly. Grid construction rejects count overflow, missing/nonfinite heights, exhausted cells/storage/work and unrepresentable cell boundaries. Footprint is an axis-aligned closed rectangle entirely within the grid. Positive-area overlaps use min/max clipping; each owns exact area and centroid. Partial cells are **not** modified over their entire area. Histories belong only to their fixed intersection subareas. Width b=min(rectangle x extent,y extent) is the Bekker plate width. Changing footprint/grid/calibration after issuing history requires a new model/history or exact checkpoint restore; no remapping is implied.

The coefficient/formulation contract is `bekker-elastic-janosi-fixed-patch-v1`. B=kc/b+kphi, pressure envelope p=B*z^n. kc has units Pa*m^(1-n), kphi Pa*m^(-n), n is dimensionless and restricted to n>=1. Both moduli are nonnegative and at least one positive. Elastic unloading modulus E is Pa/m and must strictly exceed n*B*zMax^(n-1) at the smallest calibrated width. Caller explicitly supplies cohesion c>=0 Pa, friction tangent mu>=0 (tan of the measured friction angle), and Janosi length K>0 m. No model defaults, silently increased E, degree/radian conversion, fake calibration or terrain are supplied.

Primary source: [Project Chrono 9.0.1 SCMTerrain.cpp, commit 2617649bf687456328a122b63dc0bb64df91394a](https://github.com/projectchrono/chrono/blob/2617649bf687456328a122b63dc0bb64df91394a/src/chrono_vehicle/terrain/SCMTerrain.cpp#L1354-L1426), consulted 2026-10-05. The source defines elastic pressure, Bekker correction, plastic sinkage and Janosi–Hanamoto shear. Our fixed subarea geometry and interval work integration are separate explicit discretizations, not an equivalence claim to complete SCM.

For each subarea, current geometric sinkage z=max(hInitial-hInterface,0), peak q, irreversible sinkage zp and shear travel j are history. Elastic trial pE=E*(z-zp); if z exceeds the old peak, set qNew=z, pNew=B*z^n and zpNew=z-pNew/E. Otherwise pNew=max(pE,0), retaining q/zp; exactly at z=q use the envelope value to preserve its pressure bits at the shared branch junction. The slope condition guarantees nondecreasing irreversible sinkage. Recoverable energy U=A*p^2/(2E). Plastic work is Dp=A*integral(qOld...qNew, B*z^n*(1-n*B*z^(n-1)/E) dz) when peak grows, otherwise zero. This is the same envelope-minus-elastic primitive, evaluated through stable power means over the rounded issued peak increment instead of subtracting close endpoint powers. For n=1 it is A*deltaPeak*B*(qOld+deltaPeak/2)*(1-B/E). This distinguishes irreversible compaction from recoverable unloading; shear has no recoverable spring energy. Loss/elastic displacement/energy/force/travel underflow or cumulative increments that cannot advance representably fail explicitly.

The interval uses constant prescribed interface-minus-terrain velocity. hNew=hOld+dt*vz, so no contradictory height/displacement input exists. Force is an **interval mean**, not endpoint pressure. For nonzero original requested deltaRawSinkage=-dt*vz, integrate pressure directly along that requested displacement: zero below the retained plastic sinkage, elastic E*(z-zp) up to the retained peak on reload, then B*z^n on new loading; unloading follows the elastic branch until separation. Interval lengths are split at contact and peak crossings, including an initial geometric gap. At exactly zero requested displacement pMean=pNew. The power mean for a>0 and L/a<=1 uses a^n*expm1((n+1)*log1p(L/a))/((n+1)*L/a); a=0 and large ratios use their direct/scaled primitives. No small-speed clamp or endpoint fallback exists. Typed arithmetic failure rejects nonfinite or unrepresentable positive integral factors. Endpoint hNew/q/U are still issued from rounded hOld+dt*vz, and endpoint pNew is separately reported. Before shear is computed, each cell independently checks A*pMean*deltaRawSinkage-(Unew-Uold+Dp) against the unchanged caller energy tolerance scaled only by normal work/energy, preventing shear or other cells from hiding normal cancellation. Returned force is never generated from this residual. Pressure/load/sinkage/speed/travel/width/dt calibrated limits are enforced.

Shear is mobilized only under positive mean compressive pressure. ds=dt*norm(vx,vy), jNew=jOld+ds. Janosi stress magnitude tau(j)=(c+mu*pMean)*(1-exp(-j/K)); the interval mean integrates that expression exactly over [jOld,jNew]. Shear direction opposes the current slip vector; zero tangent speed returns zero shear and retains travel. Reversal switches direction and retains accumulated absolute travel, a declared dissipative mobilization-memory approximation with no static stick or reversible shear. No epsilon speed or empirical smoothing. Mean mobilization uses expm1 and a bounded 32-term alternating series for small travel ratio to avoid subtractive cancellation; arithmetic exhaustion/nonfinite/underflow fails explicitly.

Per-cell force acts on the interface, and its opposite acts on terrain at the same centroid/current interval geometry. Sum about-point moments from actual centroid cross force. No pure couples are modeled. Original interface work is computed from the returned **world** force times each prescribed body's displacement; normal/shear work is computed independently from local constitutive quantities. Original Winterface+delta(U)+Dp+Ds must satisfy caller energy tolerance, with nonnegative Dp/Ds and pressure/strength limits. Elastic unloading may deliver positive interface work, exactly bounded by released U. Returned cumulative compaction/shear loss is not clamped. The model publishes no pressure-independent cohesive adhesion or normal damping.

## Runtime Flows
Bounded grid constructor -> source-byte charges -> fixed cell validation. Initial history clips each cell and rejects initially loaded configurations -> sealed virgin accepted state. Evaluate validates exact current references, revision/time, unchanged footprint -> reserves output/workspace -> cell-local calculations and independent force/work/energy reductions -> checks cancellation -> sealed trial. Accept compares the full base value before returning the candidate. A failed evaluate/accept never changes its accepted input or returns a partial trial. Checkpoint is an immutable issued value; restore charges full source/cell comparisons and requires exact grid/calibration/footprint equality.

## State, Ownership, and Lifecycle
All public inputs/results/checkpoints/history are immutable Sendable values. Grid heights and subarea-history arrays retain value-semantic owned backing. Only exclusive inout LoadWork and operation-local output arrays/counters mutate. No public history/checkpoint/trial constructor permits fabricated accepted state. Trial privately retains exact base/candidate states; caller owns acceptance/branch selection. Sequence increases once on a successful trial; start time equals accepted time and dt must produce a strictly later finite time. Checkpoint/restore preserves sequence, time, grid/calibration/frame/source, subarea state and cumulative energy. No actor/global cache, pointer, target-specific raw state or weakened Sendable contract.

## Failure, Concurrency, and Constraints
Typed errors distinguish invalid grid/calibration/policy/input, bounds/storage/work, source/time mismatch, changing footprint, initially loaded state, calibration envelope, nonfinite/sequence arithmetic, original physical rejection and Core/Load suppliers. Cancel before each metadata byte/cell/series term and before publication through qualified LoadWork. Logical work: one per metadata UTF8 byte, grid admission/cell overlap/cell response or equality cell, plus each small-series term and fixed operation publication. Initial history reserves 256+16*N scalar slots; trial reserves 384+40*N; accept/checkpoint/restore 256 slots plus borrowed-array scan work, with retained result composition budget caller-owned. N=rows*columns is overflow-checked and caller-limited. Arrays allocate only once per output, capacity <=N. These are component scalar/storage/work bounds, not measured memory/latency promises. Platform pow/expm1 select only real Darwin/WASILibc/Glibc implementations; an unavailable platform fails compilation. No target-specific state/concurrency change.
