## Architecture
```text
independent MJCF fixture + bounded caller ledgers
 -> public adapter protocol -> XML + actual native compiler
 -> caller makeState -> original body pose/motion + sensor/power/equality witnesses
 -> canonical MJCF replay/export/import + native codec/decode/recompile
 -> original expected values or exact typed refusal + consumed work
 -> identical synchronous cases in Native tests and ordinary/Embedded @main
```

## Contracts and Invariants
Rotated slide moves along world Y with original ref=2m; attached fixed body inherits velocity and must retain its own inertia. Explicit rotated diagonal inertia has independently expected body tensor diag(3,2,4). Offset hinge at parent point (1.5,0,0), q=pi/2 from a 90-degree ref, has body origin (1.5,-0.5,0), angular speed 2rad/s and origin speed (1,0,0)m/s. Expected tendon/motor lengths and power derive directly from original coef/gear/ref, not from imported gradients. Equality q-0.25m uses R=0.5m, S=0.2m: initial normalized g=-0.5, Jx=0.4; nonzero original residual must remain visible. Every named field/loss/default source remains tied to its original XML node and source revision.

Failures must be the expected typed MJCF/supplier reason: unsupported charts/laws/schema, missing inertia, duplicate identity, dangling reference, nonlinear equality, absent loss consent, wrong stamp, control shape, original domain, malformed XML, resource and cancellation. Catching a generic failure is insufficient. Successful export must preserve original default hierarchy and semantic fields; native omission must return explicit nativeSidecars loss and original source. No fixture treats nonzero equality residual as successful assembly.

Opaque CAD witness supplies a separately attributed geometry representation and owned asset bytes. Imported body/pose must retain those exact caller records; original MJCF geom and external filename remain source-attributed losses. Their presence must never supply invented native geometry or a downloaded resource.

## Runtime Flows
Each case constructs finite policies and exclusively local work. Import, makeState, sampling, export, fresh reimport or native decode/recompile occur in causal order; any unexpected failure stops the case. Synchronous public @main prints a witness only after that case returns successfully. Native async cancellation is separately awaited and not generalized to synchronous WASI task scheduling.

## State, Ownership, and Lifecycle
Immutable fixture strings, imported results and expected constants. Mutable ledgers and arrays are operation-local; no shared fixture cache, I/O or mutable static storage. Test-support import may vary by composition; production owners, Sendable contracts and algorithms do not vary by target. No unsafe access or actor lifetime is introduced.
