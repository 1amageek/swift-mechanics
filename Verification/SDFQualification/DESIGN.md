## Contracts and Invariants
Nested/static fixture has forward nested `relative_to`, separate `attached_to`, world/model transforms and original link tensor orientation/COM. Expected world poses and inertia diagonal are independently calculated; the gravity oracle is `F=m*g`, `U=-m*g.dot(COM)` at the actual transformed COM. Dynamic hinge fixture sets compiled q/v/acceleration ranges and checks actual motion of a frame whose coordinates were originally relative to a different, stationary attached frame; this distinguishes pose from attachment semantics. Euler order and quaternion vector conventions have independent orientation expectations.

Original unknown sensor/material/plugin/geometry XML must be prohibited by default. Caller-selected loss mode must retain source/node/asset root references, avoid invented collision geometry, and export independently authored normalized bytes. Export remains an original snapshot even after a changed state is evaluated. Wrong source or state revision must refuse rather than return stale motion/bytes. Semantic failures include version, unknown/duplicate names, pose/attachment cycles, world-parent joints, unsupported joint/placement/include/automatic inertia, invalid mass/axis/number/unit policy and asset traversal. Capacity cases inspect XML, semantic storage/operations/iterations, named-record/token limits, compiler and gravity limits without successful partial publication.
