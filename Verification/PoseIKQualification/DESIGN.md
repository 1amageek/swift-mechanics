## Architecture
```text
physical descriptor -> real compiler -> immutable tree
    -> public PoseIK solve -> original snapshot/evidence
    -> independent SI points / scalar rotation matrices / loop polynomial
original admitted KKT callbacks (testable access)
    -> analytic J/H -> independent central differences of original residuals
```

## Contracts and Invariants
Seven synchronous cases cover Cartesian points with rotated anchors, local orientation and pose, redundant-coordinate reference selection, timed quadratic loop rows, actual task/KKT derivatives, singular and bounded refusals, and source/work/cancellation failures. An eighth Native test awaits a genuinely cancelled Task. SI tolerances are fixed in source before execution. Original rows, scales, time, branch, bounds, query/tree identities and actual compiler provenance remain unchanged.

Derivative inspection uses `@testable` access to the producer module compiled with `-enable-testing`; it calls the real admission, task evaluator and KKT provider. Finite differences are an independent fixture oracle, never a production fallback. Scalar Taylor sine/cosine and matrix products reconstruct the selected rotations independently of the kinematic supplier. This is pointwise numerical evidence, not a uniform libm enclosure or engine equivalence claim.

## State, Ownership, and Lifecycle
Inputs/services/results are immutable Sendable values. Each case exclusively owns its work and temporary arrays. No shared mutable state, unsafe pointers or target-specific isolation. Public calls consume the same physical fixtures as tests.

## Failure, Concurrency, and Constraints
All supplier failures are preserved in a typed qualification error. A refusal is verified by its original typed cause; it never becomes a success witness. Task cancellation is awaited. The earlier original2363 thin-consumer plan was not executed; that depot disappeared during root capacity recovery. The private consumer imports and links only this coherent producer. Pinned Swift6.4.0, macOS13, Native SwiftPM jobs4 and WMO threads4 remain explicit. Root owns the cold lease. One storage baseline covers producer and consumer, with an8GiB private allocated-size cap,4GiB global free floor and bounded command watchdogs (setup900s, tests60s, public120s). Old thin128MiB policy and receipts do not qualify this new producer.
